## 컴포넌트 크기 기준 (사용자 결정: GPT 수준의 완성도)

배치와 흐름은 Claude 안을 따르되, 크기·여백·글자 크기는 GPT 목업(`received/gpt/MOCKUP_E_price_result.html`)에서 잰 값을 기준으로 맞춥니다.
Claude 프로토타입은 글자가 작고 카드 간격이 들쭉날쭉해, 같은 배치라도 GPT 쪽이 더 정돈돼 보였기 때문입니다.

## 쓰지 않거나 고쳐서 쓸 것

- **GPT "비교대상에서 제외(사유 기록)" 버튼:** 운영 앱은 저장소에 쓸 수 없어 보류합니다.
- **Claude 프로토타입의 예시 숫자:** 공급사 ○○, M30·M50 모델, M40 연도별 건수는 프로토타입용으로 만든 값입니다. 실제 화면에는 실제 데이터를 씁니다.
- **Claude 견적서 표의 M40 "범위 밖":** 6,500,000원은 최고 6,585,500원보다 낮아 실제로는 범위 안입니다. 판정은 "가운데 값보다 N% 이상 높음 → 확인 필요"처럼 차이 % 기준으로 정합니다.
- **Claude 프로토타입 가격 막대:** 최저값과 가운데 값이 가까우면 글자가 겹칩니다. 구현할 때 겹치지 않게 배치합니다.
- **GPT 목업의 자료 기준일 위치:** 맨 아래에 있는 것을 결론 근처 칩으로 올립니다.
- **메뉴 이름 "병원 뉴스", "병원 경영 비교":** 이 두 화면은 다른 작업 흐름에서 만들고 있어, 이름을 바꿀 때 그쪽과 맞춥니다.
