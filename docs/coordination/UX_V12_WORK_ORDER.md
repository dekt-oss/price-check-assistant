# 병원 구매정보 도우미 UX v1.2 작업지시서 (가격 결과 화면 탐색)

- 작성: 2026-10-14 · 기준 main `06cabfa` · 운영 배포 마커 v25
- 담당: Claude (가격 트랙 단독). 뉴스·경영 트랙은 이번 범위 밖이다.
- 근거: 2026-10-14 운영 실사용 재현(headless 브라우저)과 코드 조사. 캡처는 저장소 밖 세션 임시 폴더에 있다.

## 1. 목적

사용자가 가격 검색 결과에서 겪는 세 불편을 고친다.

1. 검색한 모델에서 같은 품목의 다른 모델로 넘어가 조사하기가 어렵다.
2. 표에 나온 거래·업체·기관을 눌러 세부로 들어가는 길이 없거나 끊긴다.
3. 표의 가격 열 정렬이 숫자 순서로 되지 않는다.

지표 계약(`docs/metrics/price.md`)의 계산 규칙은 바꾸지 않는다. 숫자를 **보여 주는 방식**만 바꾼다.

## 3. 사용자 결정

- **다른 모델은 새 탭으로 연다** (2026-10-14). 원래 검색 결과가 그대로 남아 여러 모델을 나란히 비교할 수 있어야 한다.

## 4. 단계

### Q0. 배포 확인 자동화 (먼저)
- 운영 스모크가 새 배포 마커가 보일 때까지 최대 25분 기다린 뒤 검사한다. 끝까지 옛 마커면 "배포 지연"으로 따로 실패 처리해 코드 실패와 구분한다.
- 가격 측정 워크플로는 앱이 깨지 않아 전 검색이 시간 초과되면 실패 대신 그 사실을 표본으로 남긴다(2026-10-14 04:55Z 실행이 4개 모두 시간 초과로 실패).
- 완료 기준: 이후 머지 3번 동안 스모크 수동 재실행 0번.

### Q1. 표 정렬을 숫자 순서로
- 대상 표 7개: 거래 전체, 기간별, 단위·조건별, 누가 파는가, 같은 품목 모델 전체, 도입 기관, 업체 표.
- 가격·건수·수량 열은 숫자로 넘기고, 쉼표와 "원"은 Streamlit 숫자 열 형식(`column_config.NumberColumn`)으로 붙인다.
- "최저 ~ 최고" 같은 범위 열은 최저·최고 두 열로 나눈다. 단위("/ 대")는 열 이름으로 옮긴다.
- 값이 없는 칸은 빈 숫자로 두어 정렬 때 맨 뒤로 가게 한다. "나라장터 거래 없음"·"조회 불가" 같은 상태는 별도 글자 열로 남긴다.
- 함께 넣는 작은 수정 3개(v1.1 마감 테스트에서 발견):
  - 견적이 최고 거래가보다 높지만 중앙값 ±20% 안이면 두 기준이 다르다는 것을 카드에 한 줄로 적는다.
  - 결과 카드의 낮은 견적 문장에 "단위·구성 확인" 안내를 넣는다.
  - 견적 입력칸 접근성 이름을 화면 라벨 "내 견적 단가"와 맞춘다.
- 완료 기준: 7개 표 모두 내림차순 첫 행이 실제 최댓값이다(운영 확인). 테스트가 각 표의 가격·건수 열이 숫자형임을 강제한다.

### Q2. 다른 모델을 새 탭으로 열기
- 상위 모델 목록(거래 건수 많은 모델, 납품 기관 많은 모델)의 모델 이름을 새 탭 링크로 바꾼다.
- 같은 품목 모델 전체 표를 접힌 칸 밖으로 꺼내고, 모델 이름 열을 새 탭 링크 열(`column_config.LinkColumn`)로 바꾼다. 셀을 누르면 바로 열려야 한다. 체크박스 선택은 없앤다.
- 링크 주소는 운영 주소 기준 `?q=<모델>&identity=<식별값>` 형태다. 지금 같은 화면 이동에서 쓰는 식별값을 그대로 넣어 새 탭이 같은 모델을 정확히 연다.
- 다른 화면의 같은 화면 이동 버튼(비슷한 품목, 업체명 탐색 등 `_open_model_from_overview`를 부르는 곳)도 같은 규칙으로 바꿀지 Q2 착수 때 목록을 만들어 정한다. 기본은 "다른 모델로 가는 것은 모두 새 탭"이다.
- 확인할 위험: Streamlit Cloud는 앱을 iframe 안에 띄운다. 상대 주소는 안쪽 주소(`/~/+/`)로 열릴 수 있으므로 바깥 운영 주소로 열리는지 먼저 시험한다.
- 완료 기준: SJ-DFM100 결과에서 다른 모델 이름을 한 번 누르면 새 탭에 그 모델 결과가 뜨고, 새 탭 주소창 `q=`가 그 모델이며, 원래 탭은 그대로다(운영 확인).

### Q3. 눌러서 세부로 가기
- 거래 원문 창: 같은 행을 다시 눌러도 열린다. 창을 연 뒤 행 선택을 비우는 방식으로 고친다.
- 누가 파는가·업체 표: 행을 고르면 거래 전체 표가 그 업체의 거래만 보이도록 거른다. 거른 상태와 "전체 보기" 버튼을 표 위에 보인다.
- 도입 기관 표: 지금처럼 원문 창을 연다(재클릭 수정 포함).
- 기간별 표: 연도 행을 고르면 거래 전체 표를 그 연도로 거른다.
- 완료 기준: 결과 카드에서 거래 하나의 원문(납품요구번호·기관·업체·단가)까지 어느 표에서 출발해도 2번 클릭 이내다. 같은 행 재클릭이 원문 창을 다시 연다(운영 확인).

### Q4. 자동 점검
- 운영 스모크에 세 단계를 더한다: 거래 총액 내림차순 첫 값이 최댓값인지, 다른 모델 링크가 새 탭 주소를 갖는지, 같은 거래 행 재클릭이 원문 창을 여는지.
- 대시보드 배포 마커와 스모크 마커를 v26으로 함께 올린다(`tests/test_ux_v11_integration.py`가 일치를 강제).

## 6. 공통 규칙
- 새 작업은 `.worktrees/<이름>` 워크트리에서 한다. main 체크아웃에서 커밋하지 않는다.
- CI 초록일 때만 머지한다. 스쿼시 머지 뒤 작업 브랜치에 origin/main을 다시 합친다.
- 문서만 바꾼 머지도 앱을 재시작시키므로 이 문서는 Q1 코드 PR에 묶어 머지한다.
- 판단 문구 금지어(적정, 권장, 싸다·비싸다, 절감액, 대체 가능, 안전한 제품, 원인 확정, 개선 필요·우수·부진, 인기·대표·추천)를 새 링크·버튼 문구에도 적용한다. 상위 모델 목록 제목은 지금처럼 "거래 건수가 많은 모델"처럼 사실만 적는다.
