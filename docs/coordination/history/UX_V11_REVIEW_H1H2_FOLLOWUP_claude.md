### 원인

`_issue_title_parts`가 "병원"이 든 토큰은 버리지만 **ai·진료·솔루션·도입·운영·공개·참가·확대·협력·공급·서비스·플랫폼** 같은 일반어는 토큰으로 센다. 규칙이 "공통 토큰 2개 + 2-gram Dice 0.18"이라 "AI 진료 솔루션"만 겹쳐도 2개가 채워진다. 반대로 같은 기획 연재는 제목에 겹치는 말이 적어 놓친다.

### 권고(Codex, H1 후속 2 — 작고 결정적)

1. `_TITLE_STOPWORDS`에 일반어를 추가한다(위 목록 + 소개·선보인다·발표·체감·도입식·구축·맞손). 고유명사·기관명·제품명·숫자만 "공통 토큰"으로 남게 한다. 군집 A는 `gc메디아이`·`kimes`·`부산`으로 9건이 유지되고, 메디아크 3건은 `메디아크`·`남아공`으로 따로 묶이며, 뷰노는 단독이 된다(수작업 확인).
2. 같은 매체·같은 시각(±10분)·같은 기획 태그(`[이슈플러스]`, `[단독-… ①]`처럼 대괄호 머리말이 같음)는 연재로 보고 묶는 규칙을 검토한다. 선택 사항.
3. 수정 뒤 이 50건(최신순)과 이전 50건(중요도순) **둘 다**에 다시 돌려 표를 갱신한다. 두 표본의 잘못 묶임·누락을 함께 기록해야 전체 성격이 보인다.
4. 홀드아웃 실행 방법: `.env`의 R2 읽기 설정으로 `nri.resolve_store(get_settings()).read_index()`를 읽고, `rank_entries(..., tiers)`에서 `relevant`만 골라 최신순 50건에 `cluster_news_issues(sample, keywords, tiers, roundup_terms=load_issue_roundup_terms())`. 통합 쪽 스크립트를 그대로 넘길 수 있다.
