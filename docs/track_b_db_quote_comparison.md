# 견적서 업로드와 Track B 수집 단가 비교

견적서 자동 시장조사 화면은 추출한 품명·모델명으로 DB의 Track B 납품요구 품목을 조회한다. 모델명이 있으면 정규화된 **정확한 모델 키**만 조회하고, 모델명이 없으면 품명 분류 후보를 조회한다. 최신 변경차수의 명시적 `prdctUprc`가 양수일 때만 가격을 표시한다. 견적 대비 증감률은 제품 식별 등급 A/B에만 계산하며, VAT·설치·옵션 조건을 확인하기 전에는 자동 적정성 판정에 반영하지 않는다.

Track B 수집은 별도 브랜치에서 R2 원문을 적재한다. 이 기능의 DB 테이블은 R2 원문의 조회용 색인이며 R2나 공공 API에 쓰지 않는다. 서비스 DB를 준비한 뒤 다음 순서로 적재한다.

```powershell
alembic upgrade head
python -m purchase_price.scripts.import_g2b_track_b_r2_to_db --limit 100
```

명령 출력의 `resume_cursor`를 다음 배치의 `--cursor`에 넘긴다. 각 R2 객체의 해시와 메타데이터는 읽기 단계에서 검증하고, DB에는 객체 단위 트랜잭션으로 반영한다. 동일 안정 식별자의 동일 원문은 재실행 시 중복 저장하지 않으며, 내용 충돌은 실패로 보고 마지막 완료 커서를 출력한다. 잘못된 품목 행은 `invalid_rows`로 집계하고 보고 상태를 `PARTIAL`로 표시한다.

견적 화면은 DB 연결 실패, 테이블 내 미적재, 정상 조회 0건, 식별정보 부족, 조회 상한 초과를 구분해 보여준다. 기존 공개 가격근거 검색과 직접가격 판정은 별도 경로로 유지된다.
