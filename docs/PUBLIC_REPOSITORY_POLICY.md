# Public Repository Policy

`price-check-assistant`의 초기 PoC 저장소는 Public으로 운영한다.

## 공개 가능

- 공개 웹/API에서 취득 가능한 원자료 또는 그 출처 정보
- 샘플/비식별 테스트 데이터
- 제품 식별·가격비교 알고리즘 및 테스트
- 설계·운영 문서

## 공개 금지

- 본원 실제 구매단가 및 구매이력
- 거래업체별 계약단가와 비공개 계약조건
- 실제 견적서 원본, 내부 결재문서
- 개인정보 및 내부 식별정보
- API key, token, password, private key 등 secret

## 업로드 원칙

공개 PoC에서 견적서 업로드 기능을 시험할 경우 파일은 영구 저장하지 않는 것을 기본값으로 하며, 공개 서버에는 샘플 또는 비식별 견적서만 사용한다.

## 내부 이식 시

실제 병원 데이터를 사용하기 시작하는 시점에는 저장소 공개범위, 배포환경, 접근권한, 로그/백업 정책을 다시 검토한다. Public 저장소에 내부 데이터 파일을 추가하는 방식으로 확장하지 않는다.
