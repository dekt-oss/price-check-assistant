### 11.1 실행 환경과 기준

- 운영 URL: `https://bp-price-research.streamlit.app`
- 운영 측정 시각: 2026-10-13 23:37~23:50 KST
- 측정 도구: Windows의 headless Chromium(Playwright), 한 브라우저 프로세스에서 표본마다 새 페이지 사용
- 측정 소스 기준: `28a2fd7e597ab161197177c9d012bffe0b58c875`
- 문서 브랜치 최신 기준: `9c0072785342a697de13e9e5d417dbf9e57ff58e`
- 운영 화면 마커: 40/40에서 `purchase-workspace-runtime-v24`, 결과 선택자 `#purchase-conclusion-v1` 확인. 운영 서버의 정확한 Git SHA는 화면에서 확인할 수 없어 **미검증**이다.
- p50은 정렬 표본의 가운데 두 값 평균, p95는 nearest-rank를 사용했다. `n=10`에서는 p95가 최대값과 같다.

**상태 정의**

- `warm`: 운영 앱이 깨어 있는 상태에서 집계에 넣지 않는 사전 검색 4회를 마친 뒤, 같은 브라우저 프로세스에서 표본마다 새 페이지를 열어 측정했다. 40개 표본 모두 `warmup_wait=0`, `cold=0`이었다.
- `cold`: 새 Streamlit 프로세스에서 첫 검색을 실행하는 것으로 정의했다. 운영 Reboot와 설정 변경은 하지 않았다. 로컬 1회는 기존 OS 임시 인덱스 파일을 삭제하지 않았고 R2 자격 증명도 없었기 때문에 앱 마커가 `cold=0`이었다. 따라서 이 값은 **fresh-process/no-R2 대조군**이지 정상 인덱스 cold 인수 표본이 아니다.
- `wall`: 페이지 진입부터 결론 카드까지이며 앱 진입 가능 여부와 브라우저 렌더링을 포함한다. 세부 `app_entry` 관측은 일부 표본에서 누락되어 별도 통계로 사용하지 않았다.
