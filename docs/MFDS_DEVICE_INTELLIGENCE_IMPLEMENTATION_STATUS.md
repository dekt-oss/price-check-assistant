# MFDS 의료기기 시장조사 구현 상태

작성일: 2026-09-04

## 현재 완료

### 공식 등록 / 경쟁장비

- 식약처 형명정보 API adapter (`PRDLST_NM`)
- 동일 식약처 품목 등록모델 표시
- exact-normalized 모델 identity 확인
- 동일 exact 모델이 여러 허가번호에 연결되면 ambiguous로 fail-closed
- 취소·취하/수출전용 후보 분리
- 국내 정상 동일품목 후보가 있으면 해당 후보 우선
- 국내 정상 동일품목 후보가 0건일 때만 사용목적·주요사양 기반 보조 대체탐색
- 보조 결과는 `추가 조사 후보`이며 대체 가능 장비로 자동 확정하지 않음

### 공급사

- 나라장터 verified exact-model 공개 납품근거에서 실제 공급업체 추출
- 식약처 의료기기 제조·수입 등 업허가정보 조회
- 현재 사용 가능한 식약처 업허가 업체를 2순위 supplier evidence로 변환
- 공급사 우선순위: `나라장터 실제 납품업체` → `식약처 업허가 업체` → `웹`
- 식약처 업허가 업체는 특정 모델의 공식 총판·대리점 관계를 의미하지 않는다고 명시
- 웹 공급사 탐색은 반드시 `웹` 출처로 표시

### 견적서

- `.xlsx`, `.xls` 구조적 품목/가격 추출
- 추출값 확인·수정
- 견적서 행 → 의료기기 시장조사 handoff
- handoff에는 제품명/제조사/모델명/규격만 전달
- 견적단가/총액/파일명/원본 파일은 의료기기 identity payload에서 제외
- 직접검색과 견적서 행이 공통 `PurchaseReviewInput` 계약 사용

### Safety 화면

- 별도 `의료기기 안전·공급사 확인` 화면 제공
- Safety 상태 계약: `자동조회 미연결 / 공식 확인 필요 / 공식 안전조치 일치 / 일치 미확인 / 조회 실패`
- exact 모델/허가번호를 공식 안전정보 수동 확인 키로 표시
- 식약처 공식 `회수·판매중지 / 행정처분 / 안전성서한` 링크 제공
- 회수·판매중지 공공데이터 API 명세 링크 제공
- `자동조회 미연결` 또는 향후 `0건`을 `안전`으로 표현하지 않는 문구 회귀테스트

### UDI / 표준코드 준비

- 식약처 표준코드별 제품정보 API source와 operation 존재 확인
- UDI 시스템 및 공식 API 명세 진입 경로를 화면에 제공
- request filter를 공식적으로 확정하기 전까지 모델명 서버 검색 파라미터를 추정하지 않음

## 아직 남은 구현

### 1. 회수·판매중지 자동 API adapter

현재 공식 데이터셋과 제공 필드는 확인됐지만 상세 operation/request parameter 계약이 접근 가능한 공식 명세에서 아직 확보되지 않았다.

완료 조건:
- 공식 operation/request contract 확보
- exact 모델/허가번호 조회
- exact hit 시 가격보다 우선하는 RED 경고
- API 오류와 0건 구분
- 0건 문구: `현재 연결된 공식 안전정보에서 일치 항목을 확인하지 못함`

### 2. 표준코드/UDI 자동 identity

현재 공식 표준코드별 제품정보 API의 Base URL과 operation은 확인했다.

완료 조건:
- 실제 request filter 공식 검증
- 모델 → UDI-DI/품목명/분류번호/등급/허가번호/제조·수입업체 연결
- 기존 형명정보 exact identity와 충돌 시 자동 확정하지 않음

### 3. G2B 계약정보 evidence

공식 `나라장터 계약정보서비스`의 현재 Base URL과 물품 operation은 확인했다.

완료 조건:
- 활용권한 확인
- 물품 검색 request parameter의 최신 공식 계약 확정
- 계약번호/기관/계약일/상세 URL provenance
- 계약총액을 단가로 사용하지 않음
- 수량/단위가 검증되지 않으면 직접단가 산정 금지
- Shopping 납품근거와 독립 source로 교차검증

### 4. 제조사 공식 파트너/총판 근거

웹 검색결과를 공식 총판으로 자동 승격하지 않는다.

완료 조건:
- 제조사 공식 사이트의 파트너/대리점 페이지라는 provenance 검증
- 공식 관계가 확인된 경우에만 별도 supplier evidence로 표시

### 5. 최종 화면 통합

기능 구현·실사용 검증이 끝난 뒤 진행한다.

- 직접 검색 / 견적서 업로드
- 가격근거
- MFDS 등록/경쟁장비
- 공급사
- Safety

를 최종 `구매검토` 화면으로 축약한다.

## 검증 경계

- 사용목적/주요사양만으로 AI가 자동 대체품을 생성하지 않는다.
- 웹 업체를 공식 공급업체로 확정하지 않는다.
- 지원하지 않는 API 파라미터를 추정하지 않는다.
- API 실패를 결과 0건으로 바꾸지 않는다.
- 기존 가격 A/B/C/D/X 및 ComparisonScope 계약을 완화하지 않는다.
- 실제 병원 견적/내부단가/계약정보를 Public repo에 저장하지 않는다.
