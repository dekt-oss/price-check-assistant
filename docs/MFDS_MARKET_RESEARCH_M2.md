# MFDS 의료기기 시장조사 M2

## 목적

병원 구매담당자가 특정 업체의 제안만으로 시장을 판단하지 않고 다음 순서로 독립 조사할 수 있게 한다.

```text
품목/모델
→ 식약처 국내 등록 경쟁후보
→ 나라장터 실제 공급업체
→ 식약처 업체 업허가 확인
→ 웹 보조 공급사 탐색
→ 가격근거 / 안전정보
```

## 1. 경쟁장비 기본 규칙

기본 경쟁장비 후보는 같은 식약처 품목에 등록된 모델 중 다음 조건을 만족하는 건이다.

- 취소·취하 상태가 아님
- 수출전용이 아님

같은 품목이라는 사실은 시장조사 후보라는 뜻이며 임상적 완전대체품이라는 뜻이 아니다.

### 사용목적·주요사양 기반 보조탐색

사용목적/주요사양 유사도 기반의 광범위한 탐색은 기본적으로 실행하지 않는다.

**국내 정상 동일품목 후보가 0건일 때만** 담당자에게 `대체 후보를 추가 확인` 경로를 제안한다.

보조탐색 결과는 다음 상태로 취급한다.

- 조사 후보
- 식약처 품목/허가 재확인 필요
- 임상적 대체성 미검증
- 자동 구매권고 금지

## 2. 취소·취하 / 수출전용 표시

### 취소·취하

식약처 형명정보의 취소/취하 상태가 존재하는 등록건이다. 현재 국내 신규 구매의 정상 후보로 자동 사용하지 않는다.

### 수출전용

수출 목적으로 등록된 모델이다. 국내 공급 가능 후보에서 기본적으로 숨긴다.

### UI 원칙

국내 정상 후보가 한 건 이상 있으면 취소·취하/수출전용 제품은 기본 결과에서 숨긴다.

국내 정상 후보가 0건일 때에만 `참고용 · 제외된 등록제품` expander에서 등록 이력 파악용으로 노출한다.

## 3. 공급사 우선순위

### Priority 1 — 나라장터

실제 공개 납품/구매실적에 `공급업체`가 명시된 경우 최우선 후보로 표시한다.

표시: `나라장터`

이는 현재 확보 가능한 공급사 근거 중 가장 직접적인 공공조달 실적이다.

### Priority 2 — 식약처

업체의 제조/수입/판매/임대 등 의료기기 업허가 상태를 확인한다.

표시: `식약처`

주의: 업허가가 있다는 사실만으로 특정 모델의 공식 총판/대리점이라고 판단하지 않는다.

### Priority 3 — 웹

나라장터/식약처 공식근거 외 일반 웹 탐색은 보조수단으로 제공한다.

표시: `웹`

웹에서 발견한 업체는 제조사 공식 파트너 여부와 실제 공급 가능 여부를 추가 확인해야 한다.

## 4. 모델 검색 계약

식약처 `의료기기 형명정보` API의 공식 요청변수에는 모델명(`TYPE_INFO`) 서버 검색 파라미터가 없다.

따라서 M2는 다음 원칙을 따른다.

1. 식약처 품목명 `PRDLST_NM`으로 공식 API 조회
2. 반환된 모델/형명에서 입력 모델명을 client-side exact 확인
3. 서버가 지원하지 않는 모델명 파라미터를 임의로 보내지 않음

## 5. 안전정보 UI 계약

회수·판매중지 exact 모델이 공식 Source에서 확인되면:

- 가격정보보다 먼저 배치
- 큰 빨간 경고 사용
- 회수/판매중지 사유와 기준일 표시
- 구매를 프로그램이 자동 차단하지는 않음
- 사용자가 경고를 놓치지 않도록 시각적 우선순위만 최상위로 둠

회수·판매중지 API adapter의 실제 endpoint/request contract는 공식 명세를 확인한 뒤 별도 M3/M4에서 연결한다. endpoint를 추정해 호출하지 않는다.

## 6. 비용 정책

핵심 경로는 LLM API를 사용하지 않는다.

- 식약처: data.go.kr API
- 나라장터: data.go.kr API
- 가격평가: Python rule engine
- Excel: openpyxl

사용목적/주요사양 기반 보조탐색도 현재는 투명한 웹 검색 진입점만 제공하며 AI가 자동 대체품을 생성하지 않는다.
