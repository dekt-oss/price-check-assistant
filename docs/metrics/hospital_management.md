## 1. 데이터 범위와 기존 기능

- 기본 비교 대상 8곳: 부산백, 해운대백, 일산백, 상계백, 부산대, 양산부산대, 동아대, 고신대복음.
- Master 38곳: 기본 8곳과 유사 규모 보조 병원 30곳.
- 기본 8곳 공시자료는 2016~2024, 유사 규모 보조 30곳은 2019~2024다.
- 현재 적재 최신 연도는 2024다. 현재 연도 실적처럼 표현하지 않는다.
- 회계자료가 없는 값은 `None`/`자료 없음`으로 유지한다.

현재 구현에는 회계기간 불일치 경고, 선택형 AI 경영 설명, ALIO 공시 수집 경로, KHIDI 원천·월별 갱신 흐름, 주간 Markdown/Excel 리포트가 있다. 주간 리포트는 공시 계산값, 선택적으로 최근 7일 뉴스 제목·링크, 선택적으로 계산값만 입력한 AI 설명을 담아 Actions artifact와 R2에 게시한다. 화면은 추이 4종(의료수익·인건비율·재료비율·의료이익률), 리포트는 3종(의료이익률 제외)을 만든다. 병상당 인건비·재료비는 방향을 좋음/나쁨으로 판정하지 않는 `neutral` 지표다.

## 2. 비교군 5종과 병상수

| 키 | 화면 이름 | 현재 규칙 |
| --- | --- | --- |
| `region` | 지역 경쟁군 | 같은 지역의 기본 병원 |
| `network` | 동일 의료원 | 같은 의료원·네트워크의 기본 병원 |
| `similar_size` | 유사 규모 | 화면/CLI가 명시한 병상 범위에서 전체 Master 검색 |
| `same_type` | 동일 유형 | 같은 종별과 설립형태의 기본 병원 |
| `custom` | 직접 선택 | UI에서 사용자가 고른 2~10곳 |

화면과 기본 CLI는 유사 규모에 `700~850병상`을 명시한다. `HospitalMaster.peer_group()`의 기준 병원 `±100병상` fallback은 호출자가 범위를 주지 않았을 때만 동작하며 일반 화면 경로에서는 쓰지 않는다. 기준 병원과 화면에서 평균 포함 체크를 끈 병원은 비교군에서 제외한다.

병상수 출처는 (1) `hospital_master.json`의 심평원 현재 허가병상수와 기준일, (2) 회계공시 `info.bsNum`에서 적재한 해당 연도 병상수다. 유사 규모 그룹은 현재 Master 병상수를 쓰고, 연도별 병상당 지표는 해당 연도 공시 병상수를 먼저 쓰며 없을 때만 심평원 값을 쓴다(`hospital_benchmark.beds_for()`).

## 3. 지표 목록과 세부 계산

| 지표 | 단위 | 현재 계산 |
| --- | --- | --- |
| 의료수익 증가율 | % | `(당해-전년)/abs(전년) × 100` |
| 의료수익 3년/5년 CAGR | % | `(당해/정확히 3년·5년 전)^(1/n)-1) × 100`; 시작·종료값이 모두 양수일 때만 계산 |
| 의료이익률·순이익률 | % | 각 이익/의료수익 × 100 |
| 인건비율 | % | 인건비/의료수익 × 100 |
| 재료비율 | % | (약품비+진료재료비)/의료수익 × 100 |
| 약품비율·진료재료비율·관리운영비율 | % | 각 비용/의료수익 × 100 |
| 부채비율 | % | 부채/자본 × 100; 자본이 0 이하이면 자료 없음 |
| 유동비율 | % | 유동자산/유동부채 × 100 |
| 차입금 비중 | % | 차입금 합계/자산 × 100 |
| 병상당 의료수익·인건비·재료비 | 원 | 각 금액/병상수 |

총 16개이며 핵심 표는 의료수익 증가율, 의료이익률, 순이익률, 인건비율, 재료비율, 관리운영비율, 병상당 의료수익 7개다. 차입금은 직접 공시값을 우선하고 없으면 공시된 차입금 구성 항목만 합산한다.

현재 재료비 계산은 약품비·진료재료비 중 하나만 있어도 없는 쪽을 0으로 보고 부분 합산한다(`hospital_metrics.py:143-168`). 완전 합산과 구별되는 표시가 없으므로 H2 전 사용자 결정이 필요하다: **부분 합산을 유지하되 자료 상태에 표시**할지, **두 항목 중 하나라도 없으면 재료비를 자료 없음**으로 할지 미결정이다.

## 4. H2 이전 동작(5-A)과 H2 확정 계약(5-B)

### 5-A. 현재 동작

- `peer_average()`는 값이 있는 비교병원의 단순 산술평균이며 `peer_count`는 지표별 유효 n이다(`hospital_metrics.py:183-250`).
- 비율 지표 위치 허용폭은 ±1%p, 원 지표는 비교군 평균의 ±5%다. 반올림 전 Decimal 값으로 판정한다.
- `describe_findings()`는 n 최소 조건이나 개수 제한 없이 입력 행 순서대로 모든 허용폭 초과 항목을 문장화한다. 핵심 7개를 넣으므로 최대 7개다(`:326-366`).
- 최근 변화는 각 문장 뒤에 `gap_trend()` 결과를 붙인다. 연속 3개 연도의 절대 격차가 한 방향이고 부호가 뒤집히지 않을 때만 커짐/줄어듦을 표시한다(`:309-323`).
- 화면의 첫 계층은 병원/비교군 선택 → 주요 지표 표 → 해석/선택형 AI → 전체 지표 → 그래프 순이다. 첫 줄 헤더나 별도 브리핑 블록은 없다.
- AI 키가 없으면 `AI 설명 연결 설정이 아직 없습니다`를 노출한다. H2에서 선택 기능은 유지하되 상단 결정적 브리핑을 가리지 않도록 접힌 보조 영역으로 이동하고, 미연결 안내는 상단에 노출하지 않는다.

### 5-B. H2 확정 계약

- 첫 줄: `YYYY 회계연도 공시 기준 · 비교병원 N곳`. N은 선택된 비교군 수이고 지표별 n과 구분한다.
- 유효 n이 3곳 미만인 지표는 대표 차이·최근 변화에서 제외하고 `비교 보류`로 표시한다.
- 비율 차이는 `%p`, 원 지표 차이는 비교군 평균 대비 `%`로 계산한다. 허용폭은 반올림 전 ±1%p/±5%다.
- 차이 큰 지표는 `절대 차이/허용폭` 내림차순 최대 3개, 동률은 `METRIC_SPECS` 순서다.
- 최근 변화는 차이 문장과 분리해 최대 2개로 제한한다. 최근 연속 3개 연도의 격차 방향과 부호 규칙은 현재 `gap_trend()`를 유지하며, 최근 2개 연도의 절대 격차 변화량으로 정렬한다.
- 문장은 `의료수익 증가율은 비교군 평균보다 8.8%p 낮습니다.`처럼 계산 사실만 말하고 지표군별 추가 확인 자료를 한 번 안내한다.
- 화면 정보 계층은 브리핑 → 핵심 지표 → 그래프 → 비용 구조 → 전체 지표·자료 상태다. Markdown·Excel 상단도 같은 브리핑 객체와 숫자를 쓴다.
- 페이지 제목 `병원 경영 Benchmark`는 H2에서 `병원 경영 비교`로 바꾼다. 공통 메뉴 파일은 Track H 범위 밖이므로 수정하지 않는다.

H2 구현은 위 계약을 `ManagementBriefing` 한 객체로 고정했다. 화면과 Markdown·Excel 리포트는 이 객체를 함께 사용하며, 8개 기본 병원 × 5개 비교군 40조합 생성 테스트에서 예외가 없음을 확인한다. 화면 동작 변경 마커는 `hospital_benchmark.MODULES_REVISION = "2026-10-13-h2"`다.

금지 표현: 적정, 권장, 싸다·비싸다, 절감액, 대체 가능, 안전한 제품, 원인 확정, 개선 필요·우수·부진, 인기·대표·추천.

## 5. 2024년 8개 병원 × 비교군 4종 유효 n 점검

직접 선택은 사용자 선택에 따라 달라 제외했다. 화면 기본 유사 규모 범위 `700~850`을 적용했다. 각 셀은 `선택 N / 유효 n×지표 수`이며, 7개 핵심 지표의 유효 n이 조합 안에서 모두 같아 `n×7`로 줄여 적었다.

| 기준 병원 | 지역 | 동일 의료원 | 유사 규모 | 동일 유형 |
| --- | ---: | ---: | ---: | ---: |
| 부산백 | 4 / 4×7 | 3 / 3×7 | 30 / 30×7 | 2 / 2×7 |
| 해운대백 | 4 / 4×7 | 3 / 3×7 | 31 / 31×7 | 2 / 2×7 |
| 일산백 | 0 / 0×7 | 3 / 3×7 | 30 / 30×7 | 2 / 2×7 |
| 상계백 | 0 / 0×7 | 3 / 3×7 | 31 / 31×7 | 2 / 2×7 |
| 부산대 | 4 / 4×7 | 1 / 1×7 | 31 / 31×7 | 1 / 1×7 |
| 양산부산대 | 0 / 0×7 | 1 / 1×7 | 31 / 31×7 | 1 / 1×7 |
| 동아대 | 4 / 4×7 | 0 / 0×7 | 31 / 31×7 | 2 / 2×7 |
| 고신대복음 | 4 / 4×7 | 0 / 0×7 | 30 / 30×7 | 2 / 2×7 |

32개 조합 중 17개는 7개 지표 모두 n≥3, 15개는 7개 모두 n<3이다. 특히 동일 유형은 8개 전부, 동일 의료원은 4개, 지역은 3개가 대표 브리핑 전체 보류가 된다. 따라서 최소 n=3은 통계적 신뢰와 화면 공백 사이의 제품 결정이 필요하다. 현재 최종 작업지시서의 n=3은 유지하되, H2 착수 전 사용자가 유지/완화를 확인해야 한다.

재현 명령은 저장소 uv Python, `PYTHONPATH=src`에서 `load_benchmark_data()` 후 각 core 병원에 `region/network/similar_size/same_type`과 `bed_range=(700,850)`, `fiscal_year=2024`, `HEADLINE_METRICS`를 넘겨 `peer_count`를 출력했다. 임시 스크립트는 커밋하지 않았다.

## 7. 리포트 경로와 보관

화면은 Markdown/Excel bytes를 만들고 파일명은 `{병원}_경영비교_{회계연도}_{비교군}.md/.xlsx`다. CLI 기본 출력은 `artifacts/hospital-report/`, Actions artifact는 `hospital-weekly-report`, R2는 `reports/v1/<생성일>/`이다.

현재 R2 정리는 뉴스 포함 여부와 무관하게 21일보다 오래된 **날짜 폴더 전체**를 삭제한다(`generate_hospital_report.py:29-30, 101-116`). 뉴스 제목이 든 리포트만 선별 삭제하는 구조가 아니다. H2는 이 동작을 바꾸지 않고 문서·화면 표현만 정확히 맞춘다.
