# 병원 경영정보 지표·브리핑 계약

- Phase: H0
- 조사 기준: `020224cf50f9e054e02982e1fac9d319dd6b6cd1`
- 정본 코드: `services/hospital_master.py`, `hospital_metrics.py`, `hospital_benchmark.py`, `hospital_report.py`
- 원자료: `data/hospital_master.json`, `data/hospital_financial.csv`

## 1. 데이터 범위

- 기본 비교 대상: 부산백, 해운대백, 일산백, 상계백, 부산대, 양산부산대, 동아대, 고신대복음 8개 병원
- 유사 규모 보조 명단을 포함한 Master: 38개 병원
- 회계 공시연도: 2016~2024
- 최신 공시연도는 화면에서 선택한 연도이며 현재 적재분의 최신은 2024년이다. 현재 연도 실적처럼 표현하지 않는다.
- 회계자료가 없는 값은 `None`과 `자료 없음`으로 유지하고 추정하거나 이전 연도 값으로 채우지 않는다.

## 2. 비교군 5종

| 키 | 화면 이름 | 규칙 |
| --- | --- | --- |
| `region` | 지역 경쟁군 | 같은 지역의 기본 병원 |
| `network` | 동일 의료원 | 같은 의료원·네트워크의 기본 병원 |
| `similar_size` | 유사 규모 | 병상수 범위 또는 기준 병원 ±100병상, 전체 Master 사용 |
| `same_type` | 동일 유형 | 같은 종별과 설립형태의 기본 병원 |
| `custom` | 직접 선택 | 사용자가 고른 2~10개 병원 |

기준 병원은 비교군에서 제외한다. 화면에서 평균 포함 체크를 끈 병원도 평균과 그래프에서 제외한다.

## 3. 지표 목록과 계산

| 지표 | 단위 | 계산 |
| --- | --- | --- |
| 의료수익 증가율 | % | `(당해 의료수익 - 전년 의료수익) / abs(전년 의료수익) × 100` |
| 의료수익 3년 연평균 증가율 | % | `(당해 / 3년 전)^(1/3) - 1` |
| 의료수익 5년 연평균 증가율 | % | `(당해 / 5년 전)^(1/5) - 1` |
| 의료이익률 | % | 의료이익 / 의료수익 × 100 |
| 순이익률 | % | 당기순이익 / 의료수익 × 100 |
| 인건비율 | % | 인건비 / 의료수익 × 100 |
| 재료비율 | % | (약품비 + 진료재료비) / 의료수익 × 100 |
| 약품비율 | % | 약품비 / 의료수익 × 100 |
| 진료재료비율 | % | 진료재료비 / 의료수익 × 100 |
| 관리운영비율 | % | 관리운영비 / 의료수익 × 100 |
| 부채비율 | % | 부채총계 / 자본총계 × 100. 자본총계가 0 이하면 계산하지 않음 |
| 유동비율 | % | 유동자산 / 유동부채 × 100 |
| 차입금 비중 | % | 차입금 합계 / 자산총계 × 100 |
| 병상당 의료수익 | 원 | 의료수익 / 병상수 |
| 병상당 인건비 | 원 | 인건비 / 병상수 |
| 병상당 재료비 | 원 | (약품비 + 진료재료비) / 병상수 |

차입금 합계는 직접 공시된 `borrowings`가 있으면 그 값을 쓰고, 없으면 단기차입금·임직원단기차입금·유동성장기부채·장기차입금·외화장기차입금 중 공시된 값을 합한다. 하나도 없으면 자료 없음이다.

화면의 핵심 지표는 의료수익 증가율, 의료이익률, 순이익률, 인건비율, 재료비율, 관리운영비율, 병상당 의료수익 7개다.

## 4. 병상수 출처 두 가지

1. 심평원 동기화 값: `hospital_master.json`의 `bed_count`, `bed_count_as_of`. 현재 허가병상수이며 유사 규모 비교의 우선값이다.
2. 공시 일반현황 값: 회계자료 `info.bsNum`에서 적재한 `disclosed_bed_count`. 해당 회계연도의 병상수다.

연도별 병상당 지표는 같은 연도의 공시 병상수를 먼저 쓰고, 그 값이 없을 때만 심평원 현재 허가병상수를 쓴다. 화면에는 두 출처의 기준일을 분리해 표시한다. 두 값을 섞어 하나의 기준일처럼 쓰지 않는다.

## 5. 경영 브리핑 산식

### 비교군 평균과 유효 개수

- 지표마다 값이 있는 비교병원만 사용한 단순 산술평균이다.
- `평균 = 유효값 합계 / 유효값 개수`이며 화면과 리포트에 유효 비교병원 수 `n`을 함께 둔다.
- 유효값이 3곳 미만이면 해당 지표는 대표 브리핑에 넣지 않고 `비교 보류`로 표시한다.

### 차이 계산과 허용폭

- 비율 지표(`unit == "%"`): `기준 병원 값 - 비교군 평균`, 단위는 `%p`. 허용폭은 `±1%p`이며 절대 차이가 1%p 이하이면 대표 브리핑에서 제외한다.
- 금액 지표(`unit == "원"`): `(기준 병원 값 - 비교군 평균) / abs(비교군 평균) × 100`, 단위는 `%`. 허용폭은 `±5%`이며 절대 차이가 5% 이하이면 제외한다. 비교군 평균이 0이면 비교하지 않는다.
- 평균과 n은 지표별로 다시 계산한다. 한 지표의 결측값 때문에 다른 지표의 유효 병원까지 제외하지 않는다.

### 대표 문장 선택

- 차이 큰 지표는 최대 3개다.
- 정렬 점수는 `절대 차이 / 허용폭`이다. 같은 점수면 `METRIC_SPECS` 선언 순서를 따른다.
- 문장은 `의료수익 증가율은 비교군 평균보다 8.8%p 낮습니다.`처럼 사실만 쓴다.
- 최근 변화는 3개 연속 회계연도의 비교군 격차가 같은 방향으로 계속 커지거나 줄어든 경우만 사용한다.
- 최근 변화 문장은 최대 2개이며, 최근 2개 연도 사이 절대 격차 변화가 큰 순서로 고른다. 동률은 `METRIC_SPECS` 순서다.
- 원인을 단정하지 않고 지표별 추가 확인 자료를 안내한다.
- 첫 줄은 항상 `YYYY 회계연도 공시 기준 · 비교병원 N곳`이다. 여기의 N은 선택된 비교군 수이며 지표별 유효 n과 구분한다.

## 6. 금지 표현과 추가 확인 안내

브리핑은 원인 확정, 개선 필요, 우수, 부진을 사용하지 않는다. 현재 연도 실적처럼 쓰지 않는다.

| 지표군 | 추가 확인 안내 |
| --- | --- |
| 의료수익·증가율 | `의료수익 변화는 환자 수, 진료단가, 환자구성 자료를 추가 확인해야 합니다.` |
| 인건비·인건비율 | `인건비 차이는 부서별 인력과 인건비 자료를 추가 확인해야 합니다.` |
| 재료비·약품비·진료재료비 | `재료비 차이는 진료과별 사용량과 구매단가 자료를 추가 확인해야 합니다.` |
| 의료이익·순이익 | `이익 차이는 수익과 비용의 세부 계정 자료를 추가 확인해야 합니다.` |
| 부채·유동성·차입금 | `재무비율 차이는 차입 조건과 상환 일정 자료를 추가 확인해야 합니다.` |
| 병상당 지표 | `병상당 지표는 병상 가동률과 환자구성 자료를 추가 확인해야 합니다.` |
