# 공통 하네스 (모든 프로젝트 공통 규칙)

> ⚠️ 이 파일은 `dekt-oss/claude-config` 의 `shared/HARNESS.md` 에서 **자동 배달**된 사본이다.
> 여기서 고치지 말 것 — 다음 배달 때 덮어써진다. 고칠 곳은 claude-config 한 곳뿐이다.
> **프로젝트 CLAUDE.md 가 이 파일과 다르게 말하면 프로젝트 쪽이 이긴다**(머지 방식·검사 명령 등).

## 1. 완료는 말이 아니라 증거로
- "됐다·고쳤다·통과했다"는 **그 프로젝트의 검사 명령을 실제로 돌린 출력**을 보고에 붙일 때만 쓴다.
  `scripts/smoke.sh` 가 있으면 그 마지막 줄(`SMOKE OK n/n`)을, 없으면 CLAUDE.md 의 검사 명령
  (test·typecheck·lint 등) 결과 줄을 붙인다.
- 증거가 없는 문장에는 `(미검증)` 을 붙인다. 머지·배포·PR 생성은 "완료"가 아니다.

## 2. 같은 문제로 2번 실패하면 멈춘다
- 같은 오류·같은 목표로 **두 번 연속** 고치기에 실패하면 세 번째 시도를 하지 않는다.
- 멈추고 보고한다: ① 증상 ② 시도한 두 가지와 각각 왜 안 됐는지 ③ 다음 가설 하나 ④ 필요한 것(권한·정보·결정).
- 돈이 드는 호출(LLM·이미지·영상·유료 API)이 실패하면 **한 번**에서 멈추고 원인부터 본다.

## 3. 만든 AI 와 검사하는 AI 를 나눈다
- 코드를 바꾼 작업은 커밋·PR 직전에 **독립 검사**를 받는다: 수정 권한 없는 서브에이전트를 새 맥락으로 띄워
  변경 diff 만 주고(내 결론·가설은 주지 않는다) ✅/⚠️/❌ 로 판정받는다.
- 프로젝트 전용 검사 AI(예: `aria-reviewer`)가 있으면 그것을, 없으면 `code-reviewer` 를 쓴다.
- ❌ 가 있으면 고친 뒤 **다시 검사**받는다. 검사 결과 요약은 PR 설명에 적는다.
- 문서만 바꾼 작업은 생략할 수 있다(보고에 "문서만 — 검사 생략" 이라고 적는다). **단, 프로젝트 CLAUDE.md 가
  검사를 필수로 정했으면(예: Aria) 문서만 바꿔도 생략하지 않는다.**

## 4. 돈 드는 대량 작업은 승인 먼저
- 유료 LLM·이미지·영상 API 를 수백 번 이상 부르거나 비용이 예상되는 작업은 무료 대안(기존 결과 재사용·규칙·SQL·
  표본 소량)을 먼저 찾고, "N건 · 약 ₩X" 를 말한 뒤 **명시적 승인**을 받는다. "전수조사 해봐" 는 승인이 아니다.

## 5. 지어내지 않는다 · 우회하지 않는다
- 외부 API 형식·가격·URL·데이터는 **실제로 확인한 것만** 쓴다. 확인 못 하면 확인 못 했다고 쓴다.
- 사이트가 봇 차단·요청 제한을 걸면 멈춘다. UA 위장·IP 변경·프록시 같은 우회를 하지 않는다.
- 문서에 적힌 옛 상태를 그대로 말하지 말고 지금 상태를 실제로 확인한다.

## 6. 비밀값
- 키·토큰은 코드·커밋·로그·PR 에 쓰지 않는다. `.env` 는 커밋 금지, `.env.example` 만 커밋.
- 브라우저·앱 번들로 나가는 변수(`NEXT_PUBLIC_*`·`EXPO_PUBLIC_*`)에는 공개 가능한 값만 둔다.

## 7. 지시서(CLAUDE.md)를 짧게 유지한다
- CLAUDE.md 에는 **항상 지킬 규칙과 문서 지도**만 둔다. 사고 경위·운영 이력·실측 기록은 `docs/` 로 보내고 링크만 남긴다.
- 규칙을 하나 더할 때는 지울 수 있는 낡은 규칙이 있는지 같이 본다.
- 줄이는 대상은 이력·경위다. 헌법·불변 원칙·최상위 기준 절(예: Aria 의 "분석 헌법")은 이 규칙을 이유로 줄이지 않는다.
- 여러 프로젝트에 공통인 규칙이면 프로젝트 CLAUDE.md 가 아니라 claude-config `shared/HARNESS.md` 에 넣는다.

## 8. 보고 형식
- 모든 답은 두괄식(결론 먼저). 코드·설정·데이터·문서를 바꾼 턴의 마지막 보고는 다섯 덩어리
  **시키신 것 / 문제가 뭐였나 / 어떻게 해결했나 / 이렇게 확인하세요 / 다음 작업** 순서로, 코드를 안 읽는 사람이
  이해하는 쉬운 말로 쓴다. 자세한 형식: `work-completion-report` 스킬.
